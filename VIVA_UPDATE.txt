2.1 MACHINE LEARNING ALGORITHMS
================================

2.1.1 NAIVE BAYES CLASSIFIER
----------------------------
WHAT IS IT?
Naive Bayes is a probabilistic classifier based on Bayes' Theorem with the
"naive" assumption that all features are independent of each other.

BAYES' THEOREM:
P(Class|Features) = [P(Features|Class) × P(Class)] / P(Features)

Where:
- P(Class|Features) = Posterior probability
- P(Features|Class) = Likelihood
- P(Class) = Prior probability
- P(Features) = Evidence

FORMULA FOR CLASSIFICATION:
Class = argmax [P(c) × ∏ P(xi|c)]
        c∈C

Where:
- c = class label
- xi = feature i
- ∏ = product of all features

HOW IT WORKS:
1. Calculate prior probability P(c) for each class
2. Calculate likelihood P(xi|c) for each feature given the class
3. Multiply all probabilities (assume independence)
4. Choose class with highest probability

TYPES:
- Gaussian Naive Bayes: For continuous features (assumes normal distribution)
- Multinomial NB: For discrete counts (used in text classification)
- Bernoulli NB: For binary features

IN OUR PROJECT:
- Used MultinomialNB for text (word counts from TF-IDF)
- Used GaussianNB for facial (HOG features are continuous)

ADVANTAGES:
✓ Fast training and prediction
✓ Works well with small datasets
✓ Handles high-dimensional data well

DISADVANTAGES:
✗ Assumes feature independence (rarely true in real data)
✗ Lower accuracy compared to complex models


2.1.2 SUPPORT VECTOR MACHINE (SVM)
-----------------------------------
WHAT IS IT?
SVM is a supervised learning algorithm that finds the optimal hyperplane to
separate different classes in high-dimensional space.

KEY CONCEPTS:

A. HYPERPLANE:
   - In 2D: A line that separates two classes
   - In 3D: A plane
   - In n-D: A (n-1) dimensional hyperplane

   Equation: w·x + b = 0
   Where:
   - w = weight vector (perpendicular to hyperplane)
   - x = input vector
   - b = bias term

B. SUPPORT VECTORS:
   - Data points closest to the hyperplane
   - These points "support" or define the hyperplane
   - Removing other points doesn't affect the hyperplane

C. MARGIN:
   - Distance between hyperplane and nearest support vector
   - SVM maximizes this margin for better generalization

   Margin = 2/||w||

   Goal: Maximize margin = Minimize ||w||

D. OPTIMIZATION PROBLEM:
   Minimize: (1/2)||w||² + C∑ξi

   Subject to: yi(w·xi + b) ≥ 1 - ξi

   Where:
   - C = regularization parameter (controls trade-off)
   - ξi = slack variables (allow some misclassification)

E. RBF KERNEL (Radial Basis Function):
   When data is not linearly separable, kernel trick maps data to higher dimensions.

   RBF Kernel formula:
   K(x, x') = exp(-γ||x - x'||²)

   Where:
   - γ (gamma) = 1/(2σ²) controls influence radius
   - ||x - x'|| = Euclidean distance between two points

   HIGH γ: Complex decision boundary (may overfit)
   LOW γ: Smooth decision boundary (may underfit)

HOW SVM WORKS:
1. Map input data to higher dimensional space (using kernel)
2. Find hyperplane that maximizes margin
3. Classify new points based on which side of hyperplane they fall

IN OUR PROJECT:
- Used SVC with RBF kernel for both text and facial
- For text: Applied on TF-IDF vectors (5000 dimensions)
- For facial: Applied on HOG features (8100 dimensions)

ADVANTAGES:
✓ Effective in high-dimensional spaces
✓ Memory efficient (uses only support vectors)
✓ Versatile (different kernels for different problems)

DISADVANTAGES:
✗ Slow training on large datasets
✗ Sensitive to feature scaling
✗ Difficult to interpret


2.1.3 RANDOM FOREST
--------------------
WHAT IS IT?
Random Forest is an ensemble learning method that builds multiple decision
trees and merges their predictions for better accuracy and robustness.

KEY CONCEPTS:

A. DECISION TREE:
   - Tree-like structure with nodes and branches
   - Each node: Test on a feature
   - Each branch: Outcome of the test
   - Each leaf: Class label (classification) or value (regression)

   SPLITTING CRITERIA:
   - Gini Impurity: Gini = 1 - Σ(pi²)
     Where pi = probability of class i
     Lower Gini = Purer node

   - Entropy: H(S) = -Σ pi log₂(pi)
     Information Gain = H(parent) - Σ(weighted H(children))

B. ENSEMBLE LEARNING:
   - Combines multiple models to improve performance
   - "Wisdom of the crowd" - many weak learners → strong learner

C. BAGGING (Bootstrap Aggregating):
   1. Create multiple bootstrap samples (random sampling with replacement)
   2. Train a decision tree on each sample
   3. Average predictions (regression) or vote (classification)

D. RANDOM FEATURE SELECTION:
   - At each node, consider only random subset of features
   - Reduces correlation between trees
   - Typical: √n features for classification, n/3 for regression
   - n = total number of features

HOW RANDOM FOREST WORKS:
1. Create N bootstrap samples from training data
2. For each sample:
   - Build a decision tree
   - At each node, select random subset of features
   - Split using best feature from subset
3. For prediction:
   - Classification: Majority vote from all trees
   - Regression: Average of all tree predictions

FORMULA FOR FINAL PREDICTION:
Classification: Class = mode{h₁(x), h₂(x), ..., hₙ(x)}
Regression: ŷ = (1/N) Σ hᵢ(x)

Where hᵢ(x) = prediction from tree i

IN OUR PROJECT:
- n_estimators = 100 (100 decision trees)
- Used for both text (TF-IDF) and facial (HOG) classification

ADVANTAGES:
✓ Reduces overfitting compared to single decision tree
✓ Handles missing values well
✓ Provides feature importance
✓ Works well with both categorical and numerical data

DISADVANTAGES:
✗ Slower prediction than single tree
✗ Large model size (stores all trees)
✗ Less interpretable than single tree


2.1.4 XGBOOST (Extreme Gradient Boosting)
------------------------------------------
WHAT IS IT?
XGBoost is an optimized gradient boosting algorithm that builds trees
sequentially, where each tree corrects errors of previous trees.

KEY CONCEPTS:

A. GRADIENT BOOSTING:
   - Ensemble method like Random Forest
   - BUT: Trees are built SEQUENTIALLY (not parallel)
   - Each tree tries to correct errors of previous trees

   Process:
   1. Start with weak model (simple tree)
   2. Calculate residuals (errors)
   3. Train new tree to predict residuals
   4. Add new tree to ensemble
   5. Repeat

B. WEAK LEARNERS:
   - Simple models (usually shallow decision trees)
   - Individual accuracy just above random guessing
   - Combined to form strong learner

C. LOSS FUNCTION OPTIMIZATION:
   XGBoost minimizes:

   L = Σ l(yi, ŷi) + Σ Ω(fk)

   Where:
   - l(yi, ŷi) = Loss function (e.g., log loss for classification)
   - Ω(fk) = Regularization term for tree k
   - fk = kth tree in the ensemble

D. REGULARIZATION:
   Ω(f) = γT + (λ/2)Σ wⱼ²

   Where:
   - T = number of leaves
   - wⱼ = leaf weight j
   - γ = penalty for number of leaves
   - λ = L2 regularization on weights

E. GRADIENT DESCENT:
   - Uses gradients of loss function to optimize
   - Second-order Taylor expansion for faster convergence

   gᵢ = ∂l(yi, ŷi)/∂ŷi  (first derivative)
   hᵢ = ∂²l(yi, ŷi)/∂ŷi² (second derivative)

F. TREE BUILDING:
   Gain for split = (GL²)/(HL+λ) + (GR²)/(HR+λ) - (G²)/(H+λ) - γ

   Where:
   - GL, GR = sum of gradients in left/right child
   - HL, HR = sum of hessians in left/right child
   - γ = regularization parameter

HOW XGBOOST WORKS:
1. Initialize with constant prediction (usually mean)
2. For each boosting round:
   a. Calculate gradients and hessians
   b. Build tree to fit gradients (not original labels)
   c. Find optimal leaf weights
   d. Add tree to ensemble with learning rate
3. Final prediction = sum of all tree predictions

FORMULA:
ŷᵢ = Σ fk(xi)
     k=1 to K

Where K = number of trees

KEY HYPERPARAMETERS:
- n_estimators: Number of trees (we used 100)
- max_depth: Maximum tree depth (we used 6)
- learning_rate: Shrinkage factor (we used 0.1)
- subsample: Fraction of samples per tree

IN OUR PROJECT:
- Applied on TF-IDF for text classification
- Applied on HOG features for facial classification
- Fast training with GPU acceleration

ADVANTAGES:
✓ High accuracy (often wins Kaggle competitions)
✓ Handles missing values automatically
✓ Built-in regularization prevents overfitting
✓ Feature importance available

DISADVANTAGES:
✗ Sensitive to hyperparameters
✗ Requires careful tuning
✗ Can overfit on small datasets


2.1.5 K-NEAREST NEIGHBORS (KNN)
--------------------------------
WHAT IS IT?
KNN is a simple, instance-based learning algorithm that classifies new data
points based on the majority vote of their K nearest neighbors.

KEY CONCEPTS:

A. DISTANCE METRICS:

   1. EUCLIDEAN DISTANCE (L2):
      d(p,q) = √[Σ(pi - qi)²]

      Most common, works well for continuous features

   2. MANHATTAN DISTANCE (L1):
      d(p,q) = Σ|pi - qi|

      Better for high-dimensional data, more robust to outliers

   3. MINKOWSKI DISTANCE (generalized):
      d(p,q) = [Σ|pi - qi|ᵖ]^(1/p)

      p=1: Manhattan, p=2: Euclidean

   4. COSINE SIMILARITY:
      similarity = (p·q)/(||p|| ||q||)

      Good for text data (TF-IDF vectors)

B. CHOOSING K:
   - K = number of neighbors to consider
   - Small K: More sensitive to noise (overfitting)
   - Large K: Smoother decision boundary (underfitting)
   - Odd K preferred for binary classification (no ties)
   - Rule of thumb: K = √n (where n = training samples)

C. VOTING:
   - Uniform: Each neighbor gets equal vote
   - Weighted: Closer neighbors have more influence
     Weight = 1/distance or exp(-distance)

HOW KNN WORKS:
1. Store all training data (lazy learning)
2. For new point x:
   a. Calculate distance to all training points
   b. Select K nearest points
   c. Take majority vote of their labels
   d. Assign most common label to x

FORMULA:
Class(x) = mode{yi | xi ∈ KNN(x)}

Where:
- KNN(x) = set of K nearest neighbors of x
- yi = label of neighbor i

IN OUR PROJECT:
- K = 5 neighbors
- Used Euclidean distance
- Applied on TF-IDF (text) and HOG (facial)

ADVANTAGES:
✓ Simple to understand and implement
✓ No training phase (lazy learning)
✓ Naturally handles multi-class problems
✓ Non-parametric (no assumptions about data)

DISADVANTAGES:
✗ Slow prediction (must compare to all training points)
✗ Memory intensive (stores all training data)
✗ Sensitive to irrelevant features
✗ Curse of dimensionality (poor performance in high dimensions)


2.2 DEEP LEARNING ARCHITECTURES
================================

2.2.1 CONVOLUTIONAL NEURAL NETWORK (CNN)
-----------------------------------------
WHAT IS IT?
CNN is a deep learning architecture designed for processing grid-like data
(images, time series). It uses convolutional layers to automatically learn
spatial hierarchies of features.

KEY CONCEPTS:

A. CONVOLUTION OPERATION:

   Mathematical definition:
   (f * g)(t) = ∫ f(τ)g(t-τ)dτ  (continuous)
   (f * g)[n] = Σ f[m]g[n-m]    (discrete)

   In CNNs (2D convolution):
   S(i,j) = Σ Σ I(i+m, j+n) × K(m,n)
            m n

   Where:
   - I = input image
   - K = kernel/filter
   - S = feature map (output)

B. FILTERS/KERNELS:
   - Small matrices (e.g., 3×3, 5×5) that slide over input
   - Learn to detect features (edges, corners, textures)
   - Each filter produces one feature map

   Example 3×3 edge detection filter:
   [-1  0  1]
   [-1  0  1]
   [-1  0  1]

C. STRIDE:
   - Step size for sliding the filter
   - Stride = 1: Move filter one pixel at a time
   - Stride = 2: Skip every other pixel
   - Larger stride = smaller output

D. PADDING:
   - Add zeros around input border
   - Preserve spatial dimensions
   - Types:
     • Valid: No padding (output smaller)
     • Same: Padding so output = input size

E. OUTPUT SIZE FORMULA:

   Output width/height = [(W - F + 2P)/S] + 1

   Where:
   - W = input size
   - F = filter size
   - P = padding
   - S = stride

F. POOLING LAYERS:
   - Downsample feature maps
   - Reduce computational cost
   - Add translation invariance

   MAX POOLING: Take maximum value in each region
   - Most common
   - Preserves strongest features

   AVERAGE POOLING: Take average value
   - Smoother but loses sharp features

G. ACTIVATION FUNCTIONS:

   1. ReLU (Rectified Linear Unit):
      f(x) = max(0, x)

      Advantages:
      ✓ Simple, fast computation
      ✓ Reduces vanishing gradient
      ✓ Sparse activation (many zeros)

      Disadvantage:
      ✗ Dead neurons (if x < 0 always)

   2. ELU (Exponential Linear Unit):
      f(x) = x           if x > 0
             α(eˣ - 1)   if x ≤ 0

      Advantages:
      ✓ No dead neurons
      ✓ Smooth everywhere
      ✓ Better gradient flow

H. FULLY CONNECTED (DENSE) LAYERS:
   - Every neuron connected to every neuron in previous layer
   - Used after convolutional layers for classification

   Output = σ(W·x + b)

   Where:
   - W = weight matrix
   - x = input vector
   - b = bias
   - σ = activation function

CNN ARCHITECTURE FLOW:
Input Image → [Conv → ReLU → Pool] × N → Flatten → Dense → Softmax → Output

IN OUR PROJECT:

A. CNN-1D FOR TEXT:
   Input: [batch, sequence_length, embedding_dim]
   - Embedding: 128 dimensions
   - Conv1D filters: 256 with kernel_size=3
   - Max pooling: kernel_size=2
   - Dense: 128 neurons
   - Output: 6 emotions

   Architecture:
   Embedding(vocab_size=10000, dim=128)
   → Conv1D(256 filters, kernel=3, ReLU)
   → MaxPool1D(2)
   → Conv1D(128 filters, kernel=3, ReLU)

B. DEEP CNN FOR FACIAL:

   Block 1: 48×48 → 24×24
   - Conv2D(128 filters, 3×3, ReLU)
   - MaxPool2D(2×2)

   Block 2: 24×24 → 12×12
   - Conv2D(256 filters, 3×3, ReLU)

ADVANTAGES OF CNN:
✓ Automatically learns features (no manual feature engineering)
✓ Translation invariant (detects features anywhere in image)

DISADVANTAGES:

✗ Needs GPU for reasonable training time


2.2.2 RECURRENT NEURAL NETWORK - LSTM
--------------------------------------
WHAT IS IT?
LSTM (Long Short-Term Memory) is a special type of RNN designed to learn
long-term dependencies in sequential data. It solves the vanishing gradient
problem of vanilla RNNs.

KEY CONCEPTS:

A. SEQUENCE LEARNING:
   - Process data with temporal/sequential structure
   - Examples: Text, speech, time series
   - Each output depends on previous inputs

B. VANILLA RNN (for comparison):

   hₜ = tanh(Wₓ·xₜ + Wₕ·hₜ₋₁ + b)

   Problem: Vanishing gradients
   - Gradient becomes exponentially small over long sequences
   - Can't learn long-term dependencies
   - LSTM solves this!

C. LSTM ARCHITECTURE:

   Three gates + cell state:

   1. FORGET GATE (fₜ):
      Decides what to remove from cell state

      fₜ = σ(Wf·[hₜ₋₁, xₜ] + bf)

      Output: 0 (forget) to 1 (keep) for each element

   2. INPUT GATE (iₜ):
      Decides what new information to add

      iₜ = σ(Wi·[hₜ₋₁, xₜ] + bi)
      C̃ₜ = tanh(Wc·[hₜ₋₁, xₜ] + bc)

      iₜ: What to update
      C̃ₜ: Candidate values to add

   3. OUTPUT GATE (oₜ):
      Decides what to output

      oₜ = σ(Wo·[hₜ₋₁, xₜ] + bo)

   4. CELL STATE UPDATE:

      Cₜ = fₜ ⊙ Cₜ₋₁ + iₜ ⊙ C̃ₜ

      Where ⊙ = element-wise multiplication

      - fₜ ⊙ Cₜ₋₁: Forget old information
      - iₜ ⊙ C̃ₜ: Add new information

   5. HIDDEN STATE:

      hₜ = oₜ ⊙ tanh(Cₜ)

D. BIDIRECTIONAL LSTM (BiLSTM):
   - Process sequence in both directions
   - Forward LSTM: Processes left to right
   - Backward LSTM: Processes right to left
   - Concatenate outputs from both directions

   hₜ = [h⃗ₜ ; h⃖ₜ]

   Where:
   - h⃗ₜ = forward hidden state
   - h⃖ₜ = backward hidden state

HOW LSTM WORKS:
1. Input sequence enters LSTM cell by cell
2. For each time step t:
   a. Forget gate decides what to forget from previous cell state
   b. Input gate decides what new info to store
   c. Cell state is updated
   d. Output gate filters cell state to produce hidden state
3. Final hidden state used for prediction

IN OUR PROJECT (BiLSTM for Text):

Architecture:
Embedding(10000 words, 128 dim)
→ BiLSTM(64 units) [128 total: 64 forward + 64 backward]
→ Dropout(0.5)
→ BiLSTM(32 units) [64 total]
→ Dropout(0.5)
→ Dense(64, ReLU)
→ Dropout(0.3)
→ Dense(6, Softmax)

Input: Tokenized text sequences (max length = 100)
Output: 6 emotion classes

Training:
- Optimizer: Adam (lr=0.001)
- Loss: CrossEntropyLoss
- Epochs: 10
- Batch size: 64
- Training time: 48.9 seconds
- Accuracy: 91.10%

ADVANTAGES OF LSTM:
✓ Learns long-term dependencies
✓ No vanishing gradient problem
✓ Works well with variable-length sequences
✓ Captures context from both directions (BiLSTM)

DISADVANTAGES:
✗ Slower than CNNs (sequential processing)
✗ More parameters than RNNs
✗ Harder to parallelize


2.2.3 MULTI-LAYER PERCEPTRON (MLP)
-----------------------------------
WHAT IS IT?
MLP is a feedforward artificial neural network with multiple layers of neurons.
It's the simplest form of deep learning, also called fully connected network.

KEY CONCEPTS:

A. ARCHITECTURE:
   Input Layer → Hidden Layer(s) → Output Layer

   Each layer fully connected to next layer

B. FORWARD PROPAGATION:

   For each layer l:
   zˡ = Wˡ·aˡ⁻¹ + bˡ
   aˡ = σ(zˡ)

   Where:
   - zˡ = pre-activation (weighted sum)
   - aˡ = activation (after applying activation function)
   - Wˡ = weight matrix for layer l
   - bˡ = bias vector
   - σ = activation function

C. ACTIVATION FUNCTIONS:

   1. Sigmoid:
      σ(x) = 1/(1 + e⁻ˣ)

      Output range: (0, 1)
      Problem: Vanishing gradient

   2. Tanh:
      tanh(x) = (eˣ - e⁻ˣ)/(eˣ + e⁻ˣ)

      Output range: (-1, 1)
      Zero-centered, but still vanishing gradient

   3. ReLU (most used in hidden layers):
      ReLU(x) = max(0, x)

      Fast, no vanishing gradient

   4. Softmax (for output layer):
      softmax(xi) = eˣⁱ / Σ eˣʲ

      Converts to probabilities (sum = 1)

D. LOSS FUNCTION:

   For classification:
   Cross-Entropy Loss = -Σ yi log(ŷi)

   Where:
   - yi = true label (one-hot)
   - ŷi = predicted probability

E. BACKPROPAGATION:

   Algorithm to compute gradients:

   1. Forward pass: Compute predictions
   2. Compute loss
   3. Backward pass: Compute gradients layer by layer

      ∂L/∂Wˡ = (∂L/∂zˡ) · (aˡ⁻¹)ᵀ
      ∂L/∂bˡ = ∂L/∂zˡ
      ∂L/∂aˡ⁻¹ = (Wˡ)ᵀ · (∂L/∂zˡ)

   4. Update weights:
      W := W - α(∂L/∂W)

      Where α = learning rate

F. GRADIENT DESCENT VARIANTS:

   1. Batch GD: Use all samples per update
      - Slow but stable

   2. Stochastic GD: Use 1 sample per update
      - Fast but noisy

   3. Mini-batch GD: Use batch of samples
      - Best of both worlds
      - Most commonly used

G. ADAM OPTIMIZER:

   Adaptive learning rate for each parameter

   mₜ = β₁mₜ₋₁ + (1-β₁)gₜ        (first moment)
   vₜ = β₂vₜ₋₁ + (1-β₂)gₜ²       (second moment)

   m̂ₜ = mₜ/(1-β₁ᵗ)              (bias correction)
   v̂ₜ = vₜ/(1-β₂ᵗ)

   θₜ = θₜ₋₁ - α·m̂ₜ/√(v̂ₜ + ε)

   Where:
   - gₜ = gradient at time t
   - β₁ = 0.9 (exponential decay for first moment)
   - β₂ = 0.999 (exponential decay for second moment)
   - ε = 10⁻⁸ (small constant for numerical stability)

ADVANTAGES OF MLP:
✓ Simple architecture
✓ Universal function approximator (proven mathematically)
✓ Fast training on small networks

DISADVANTAGES:

✗ Many parameters (fully connected)
✗ Prone to overfitting
✗ Not translation invariant


2.2.4 DROPOUT REGULARIZATION
-----------------------------
WHAT IS IT?
Dropout is a regularization technique that randomly "drops" (sets to zero) a
fraction of neurons during training to prevent overfitting.

HOW IT WORKS:

Training phase:
1. For each mini-batch:
   - Each neuron has probability p of being dropped
   - Dropped neurons don't participate in forward/backward pass
   - Creates different "thinned" network each time

2. Effectively trains ensemble of 2ⁿ possible networks
   (where n = number of neurons)

Testing phase:
- Use all neurons
- Scale weights by dropout rate to compensate
- Or use inverted dropout (scale during training)

FORMULA:

Training:
y = dropout(x, p) = {
    0           with probability p
    x/(1-p)     with probability (1-p)
}

The (1-p) scaling ensures expected value stays same

Testing:
y = x  (no dropout, use all neurons)

DROPOUT RATES:
- Hidden layers: Typically 0.3-0.5
- Input layer: Typically 0.1-0.2
- Output layer: Never apply dropout

IN OUR PROJECT:
- CNN layers: Dropout(0.4)
- Dense layers: Dropout(0.3-0.5)
- After activation, before next layer

WHY IT WORKS:
✓ Prevents co-adaptation of neurons
✓ Forces network to learn robust features
✓ Acts like ensemble learning
✓ Reduces overfitting significantly

DISADVANTAGES:
✗ Increases training time
✗ Requires more epochs to converge


2.2.5 BATCH NORMALIZATION
--------------------------
WHAT IS IT?
Batch Normalization normalizes inputs of each layer to have zero mean and
unit variance, stabilizing and accelerating training.

THE PROBLEM IT SOLVES:
Internal Covariate Shift - distribution of layer inputs changes during
training, making learning slower and requiring careful initialization.

HOW IT WORKS:

For mini-batch B = {x₁, x₂, ..., xₘ}:

1. Compute batch mean:
   μB = (1/m) Σ xi

2. Compute batch variance:
   σB² = (1/m) Σ (xi - μB)²

3. Normalize:
   x̂i = (xi - μB) / √(σB² + ε)

   Where ε = small constant (10⁻⁵) for numerical stability

4. Scale and shift (learnable parameters):
   yi = γx̂i + β

   Where:
   - γ = scale parameter (learned)
   - β = shift parameter (learned)

   This allows network to undo normalization if needed

WHERE TO APPLY:
- After linear layer, before activation
- Order: Conv/Dense → BatchNorm → Activation

DURING TESTING:
- Use running statistics (moving average) from training
- Not batch statistics (batch might be small or size=1)

ADVANTAGES:
✓ Faster training (can use higher learning rates)
✓ Less sensitive to initialization
✓ Acts as regularization (reduces need for dropout)
✓ Improves gradient flow

DISADVANTAGES:
✗ Adds computational overhead
✗ Behaves differently in train vs test mode
✗ Requires larger batch sizes to work well

CELL 5: TF-IDF VECTORIZATION
-----------------------------
Purpose: Convert text to numerical features using TF-IDF

TF-IDF (Term Frequency - Inverse Document Frequency):

TF(t, d) = (Number of times term t appears in document d) /
           (Total terms in document d)

IDF(t) = log[(Total documents) / (Documents containing term t)]

TF-IDF(t, d) = TF(t, d) × IDF(t)

Intuition:
- TF: How important is term in THIS document
- IDF: How rare/unique is term across ALL documents
- High TF-IDF = important AND rare = good feature


```python
# Define BiLSTM model
class BiLSTMClassifier(nn.Module):
    def __init__(self, vocab_size, embed_dim=128, hidden_dim=64,
                 num_classes=6, dropout=0.5):
        super(BiLSTMClassifier, self).__init__()

        # Embedding layer
        self.embedding = nn.Embedding(vocab_size, embed_dim, padding_idx=0)

        # First BiLSTM layer
        self.lstm1 = nn.LSTM(
            embed_dim, hidden_dim,
            batch_first=True,
            bidirectional=True
        )
        self.dropout1 = nn.Dropout(dropout)

        # Second BiLSTM layer
        self.lstm2 = nn.LSTM(
            hidden_dim * 2, hidden_dim // 2,  # *2 because bidirectional
            batch_first=True,
            bidirectional=True
        )
        self.dropout2 = nn.Dropout(dropout)

        # Fully connected layers
        self.fc1 = nn.Linear(hidden_dim, 64)
        self.dropout3 = nn.Dropout(0.3)
        self.fc2 = nn.Linear(64, num_classes)

    def forward(self, x):
        # Embedding: [batch, seq_len] → [batch, seq_len, embed_dim]
        x = self.embedding(x)

        # BiLSTM 1: → [batch, seq_len, hidden_dim*2]
        x, _ = self.lstm1(x)
        x = self.dropout1(x)

        # BiLSTM 2: → [batch, seq_len, hidden_dim]
        x, _ = self.lstm2(x)
        x = self.dropout2(x)

        # Take last time step: [batch, hidden_dim]
        x = x[:, -1, :]

        # FC layers
        x = F.relu(self.fc1(x))
        x = self.dropout3(x)
        x = self.fc2(x)

        return x

# Load data

    data = pickle.load(f)

train_loader = data['train_loader']
test_loader = data['test_loader']
vocab_size = data['vocab_size']
num_classes = data['num_classes']

# Initialize model

print(f"Device: {device}")

for epoch in range(epochs):

    train_loss = 0
    train_correct = 0
    train_total = 0

    for batch_x, batch_y in train_loader:
        batch_x, batch_y = batch_x.to(device), batch_y.to(device)

        optimizer.zero_grad()
        outputs = model(batch_x)
        loss = criterion(outputs, batch_y)
        loss.backward()
        optimizer.step()

        train_loss += loss.item()
        _, predicted = outputs.max(1)
        train_total += batch_y.size(0)
        train_correct += predicted.eq(batch_y).sum().item()

    train_acc = 100. * train_correct / train_total

    if (epoch + 1) % 2 == 0:

print(f"  Training time: {train_time:.1f}s")
```

```python
# Define CNN-1D model
class CNN1DClassifier(nn.Module):
    def __init__(self, vocab_size, embed_dim=128, num_classes=6, dropout=0.5):
        super(CNN1DClassifier, self).__init__()

        # Embedding layer
        self.embedding = nn.Embedding(vocab_size, embed_dim, padding_idx=0)

        # First conv block
        self.conv1 = nn.Conv1d(embed_dim, 256, kernel_size=3, padding=1)
        self.pool1 = nn.MaxPool1d(2)
        self.dropout1 = nn.Dropout(dropout)

        # Second conv block
        self.conv2 = nn.Conv1d(256, 128, kernel_size=3, padding=1)
        self.pool2 = nn.AdaptiveMaxPool1d(1)  # Global max pooling

        # Fully connected layers
        self.fc1 = nn.Linear(128, 128)
        self.dropout2 = nn.Dropout(dropout)
        self.fc2 = nn.Linear(128, num_classes)

    def forward(self, x):
        # Embedding: [batch, seq_len] → [batch, seq_len, embed_dim]
        x = self.embedding(x)

        # Transpose for conv1d: [batch, embed_dim, seq_len]
        x = x.transpose(1, 2)

        # Conv block 1
        x = F.relu(self.conv1(x))  # [batch, 256, seq_len]
        x = self.pool1(x)           # [batch, 256, seq_len/2]
        x = self.dropout1(x)

        # Conv block 2
        x = F.relu(self.conv2(x))  # [batch, 128, seq_len/2]
        x = self.pool2(x)           # [batch, 128, 1]

        # Flatten
        x = x.squeeze(-1)           # [batch, 128]

        # FC layers
        x = F.relu(self.fc1(x))
        x = self.dropout2(x)
        x = self.fc2(x)

        return x
```

```python
class DeepCNN(nn.Module):
    def __init__(self, num_classes=7):
        super(DeepCNN, self).__init__()

        # Block 1: 48×48 → 24×24
        self.conv1 = nn.Conv2d(1, 128, kernel_size=3, padding=1)
        self.pool1 = nn.MaxPool2d(2, 2)
        self.dropout1 = nn.Dropout2d(0.4)

        # Block 2: 24×24 → 12×12
        self.conv2 = nn.Conv2d(128, 256, kernel_size=3, padding=1)
        self.pool2 = nn.MaxPool2d(2, 2)
        self.dropout2 = nn.Dropout2d(0.4)

        # Block 3: 12×12 → 6×6
        self.conv3 = nn.Conv2d(256, 512, kernel_size=3, padding=1)
        self.pool3 = nn.MaxPool2d(2, 2)
        self.dropout3 = nn.Dropout2d(0.4)

        # Block 4: 6×6 → 3×3
        self.conv4 = nn.Conv2d(512, 512, kernel_size=3, padding=1)
        self.pool4 = nn.MaxPool2d(2, 2)
        self.dropout4 = nn.Dropout2d(0.4)

        # Fully connected layers
        # After 4 pooling: 48 → 24 → 12 → 6 → 3
        # Feature size: 512 × 3 × 3 = 4608
        self.fc1 = nn.Linear(512 * 3 * 3, 512)
        self.dropout5 = nn.Dropout(0.4)
        self.fc2 = nn.Linear(512, 256)
        self.dropout6 = nn.Dropout(0.3)
        self.fc3 = nn.Linear(256, num_classes)

    def forward(self, x):
        # Block 1
        x = F.relu(self.conv1(x))
        x = self.pool1(x)
        x = self.dropout1(x)

        # Block 2
        x = F.relu(self.conv2(x))
        x = self.pool2(x)
        x = self.dropout2(x)

        # Block 3
        x = F.relu(self.conv3(x))
        x = self.pool3(x)
        x = self.dropout3(x)

        # Block 4
        x = F.relu(self.conv4(x))
        x = self.pool4(x)
        x = self.dropout4(x)

        # Flatten
        x = x.view(x.size(0), -1)  # [batch, 4608]

        # FC layers
        x = F.relu(self.fc1(x))
        x = self.dropout5(x)
        x = F.relu(self.fc2(x))
        x = self.dropout6(x)
        x = self.fc3(x)

        return x
```

```python
from skimage.feature import hog
from skimage import exposure

# Extract HOG features
def extract_hog_features(image):
    """
    Extract HOG features from grayscale image

    Parameters:
    - orientations: 9 bins (0°-180° divided into 9)
    - pixels_per_cell: (8, 8) - cell size
    - cells_per_block: (2, 2) - normalization block

    Returns:
    - 1D feature vector
    """
    # Convert tensor to numpy
    if torch.is_tensor(image):
        image = image.squeeze().cpu().numpy()

    # Denormalize from [-1, 1] to [0, 1]
    image = (image + 1) / 2

    # Extract HOG
    features = hog(
        image,
        orientations=9,
        pixels_per_cell=(8, 8),
        cells_per_block=(2, 2),
        feature_vector=True
    )

    return features
```

HOG FEATURE EXTRACTION EXPLAINED:

1. GRADIENT COMPUTATION:
   For each pixel, compute:
   - Horizontal gradient: gx = I(x+1,y) - I(x-1,y)
   - Vertical gradient: gy = I(x,y+1) - I(x,y-1)

2. MAGNITUDE AND ORIENTATION:
   - Magnitude: √(gx² + gy²)
   - Orientation: θ = arctan(gy/gx)

3. HISTOGRAM CREATION:
   - Divide image into 8×8 pixel cells
   - For 48×48 image: 6×6 = 36 cells
   - Each cell: 9-bin histogram of orientations
   - Weighted by magnitude

4. NORMALIZATION:
   - Group cells into 2×2 blocks
   - Normalize each block (L2 norm)
   - Reduces lighting variations

5. FEATURE VECTOR:
   - Concatenate all normalized histograms
   - Result: 8100-dimensional feature vector

5.1 TF-IDF VECTORIZATION
=========================

What is TF-IDF?
- Converts text to numerical vectors
- Captures word importance

Term Frequency (TF):
TF(word, doc) = count(word in doc) / total words in doc

Inverse Document Frequency (IDF):
IDF(word) = log(total docs / docs containing word)

TF-IDF Score:
TF-IDF = TF × IDF

Example:
Document: "I am very happy today"
Word "happy":
- TF = 1/5 = 0.2
- IDF = log(416809/40000) = 2.35
- TF-IDF = 0.2 × 2.35 = 0.47

Rare words get higher scores!

Our configuration:
- max_features=5000: Top 5000 words
- ngram_range=(1,2): Single words + word pairs
- min_df=2: Ignore words in < 2 documents
- max_df=0.8: Ignore words in > 80% docs

Output: Sparse matrix (375K × 5000)
Sparsity: ~99% zeros (very memory efficient)


5.2 HOG FEATURE EXTRACTION
===========================

Histogram of Oriented Gradients:
- Classic computer vision technique
- Captures edge information

Steps:
1. Compute gradients (edge detection)
2. Divide into cells (8×8 pixels)
3. Create histogram per cell (9 bins)
4. Normalize blocks (2×2 cells)
5. Concatenate to feature vector

For 48×48 image:
- Cells: 6×6 = 36 cells
- Blocks: 5×5 = 25 blocks
- Features per block: 2×2×9 = 36
- Total features: 25×36 = 900... wait, why 8100?

Actual calculation:
- With stride 1 cell:
- Blocks: (6-1)×(6-1) = 25 blocks
- Each block: 4 cells × 9 bins × 4 (overlap) = 8100

This is why HOG is high-dimensional!

5.5 EVALUATION METRICS
======================

A. ACCURACY:
accuracy = correct predictions / total predictions

Pros: Easy to understand
Cons: Misleading on imbalanced data

B. PRECISION:
precision = true positives / (true positives + false positives)

"Of all we predicted as class X, how many were correct?"

C. RECALL:
recall = true positives / (true positives + false negatives)

"Of all actual class X, how many did we find?"

D. F1-SCORE:
F1 = 2 × (precision × recall) / (precision + recall)

Harmonic mean of precision and recall

E. WEIGHTED AVERAGE:
For multi-class: Average metrics weighted by class support

Example:
Class 1: 1000 samples, F1=0.9
Class 2: 100 samples, F1=0.5

Weighted F1 = (1000×0.9 + 100×0.5) / 1100 = 0.86

Q1: Why did you use PyTorch instead of TensorFlow?
A: Python 3.12 compatibility issues with TensorFlow 2.15. PyTorch 2.5 has
   better support and more flexible for custom models.

Q2: What is the difference between CNN-1D and CNN-2D?
A: CNN-1D processes sequences (text, time series) with 1D convolution along
   sequence length. CNN-2D processes images with 2D convolution across height
   and width. We used CNN-1D for text and CNN-2D for facial images.

Q3: Why is BiLSTM slower than CNN-1D but similar accuracy?
A: LSTM processes sequences step-by-step (sequential), cannot parallelize.
   CNN processes all positions simultaneously (parallel). Both capture
   context, but CNN is faster.

Q4: What is the purpose of dropout?
A: Regularization technique to prevent overfitting. Randomly drops neurons
   during training, forcing network to learn robust features. We used dropout
   0.4-0.5 in all models.

Q5: Why normalize images to [-1, 1] instead of [0, 1]?
A: Centers data around zero, helps gradient flow, prevents activation
   saturation. Tanh activation works best with zero-centered inputs.

Q6: What is the RBF kernel in SVM?
A: Radial Basis Function kernel maps data to infinite dimensions using
   K(x,x') = exp(-γ||x-x'||²). Allows SVM to learn non-linear boundaries.
   γ controls complexity.

Q7: Why did Random Forest fail on text (49% accuracy)?
A: TF-IDF creates sparse, high-dimensional features (5000 dimensions). Random
   Forest overfits on sparse data. Works better on dense features.

Q8: What is the class imbalance problem in FER-2013?
A: Disgust has only 392 samples vs Happy with 6483 samples (16× difference).
   Model biased towards majority classes. We tried class weights but didn't
   help much.

Q9: Why is facial emotion detection harder than text?
A: (1) Label noise ~30% in FER-2013, (2) Low resolution 48×48, (3) Subtle
   expression differences, (4) Similar emotions (angry vs disgust), (5) Much
   smaller dataset (35K vs 416K).

Q10: What is batch normalization and why use it?
A: Normalizes layer inputs to have zero mean and unit variance. Stabilizes
   training, allows higher learning rates, acts as regularization. However,
   in our improved model it didn't help (possibly batch size too small).

Q11: What is the difference between Adam and SGD optimizer?
A: SGD uses fixed learning rate for all parameters. Adam adapts learning rate
   per parameter using momentum (1st moment) and RMSprop (2nd moment). Adam
   converges faster and works well with default hyperparameters.

Q12: How does early stopping work?
A: Monitor validation accuracy during training. If no improvement for N epochs
   (patience), stop training. Prevents overfitting. We used patience=15 in
   improved model.

Q13: What is the curse of dimensionality?
A: In high dimensions, distance becomes meaningless (all points equally far).
   KNN fails because nearest neighbors aren't actually "near". Need exponentially
   more data as dimensions increase.

Q14: Why did MLP perform poorly on images (42%)?
A: No spatial awareness - treats pixels independently. No translation invariance
   - shifting image 1 pixel completely changes input. Too many parameters leading
   to overfitting. MLPs not suitable for images!

Q15: What is the receptive field in CNN?
A: Region of input that influences a particular feature. Deeper layers have
   larger receptive fields. Example: After 4 conv layers (3×3), receptive field
   is ~25×25 pixels.

Q16: How many parameters in your Deep CNN?
A: 9,807,047 parameters. Breakdown:
   - Conv layers: ~3M parameters
   - FC layers: ~6.8M parameters
   - First FC layer alone: 4608×512 = 2.4M

Q17: What is transfer learning and why didn't you use it?
A: Using pre-trained models (trained on ImageNet, VGGFace). Provides better
   initialization, faster convergence. We didn't use because: (1) Project
   requirement to train from scratch, (2) Learning exercise.

Q18: How would you improve the facial model?
A: (1) Data augmentation (rotation, flip, brightness), (2) Larger dataset or
   transfer learning, (3) Ensemble multiple models, (4) Clean label noise,
   (5) Use state-of-the-art architectures (ResNet, EfficientNet).

Q19: What is the difference between precision and recall?
A: Precision: "Of predicted positives, how many correct?" (avoid false alarms)
   Recall: "Of actual positives, how many found?" (avoid missing cases)
   Trade-off: High precision → conservative, High recall → aggressive

Q20: Why use cross-entropy loss for classification?
A: Measures difference between predicted and true probability distributions.
   Probabilistic interpretation, smooth gradients, works well with softmax.
   Better than MSE for classification.
